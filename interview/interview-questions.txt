How to improve performance in Microservices?
1. Use Lightweight Protocol (like GRPC over REST)
2. Reduce Network Hops
3. Caching (Memory Cache: Caffeine, Distrubuted Cache: Redis)
4. Asynchronous Processing
5. Reduce Latency (Resilience4j: Circuit Breaker, Rate Limiter, Retry Pattern)
6. Database: Indexing, Batch Processing
7. Messaging and Event Driven Architecture
(Kafka)
8. Infrastructure (Auto Scaling, Load Balancing, CDN)
9. Observability and Profiling (JProfiler, Actuator)
10. Metrics: Expose Prometheus Metrics -> Grafana Dashboard -> Analyze Latency and Throughput
